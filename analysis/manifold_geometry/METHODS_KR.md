# 측정 방법 설명 + 결과 (PR · TwoNN · MLE · Cdim · pc95)

`analysis/manifold_geometry/`의 다섯 지표가 수학적으로 무엇을 재는지, 구현에서
무엇이 잘 안 되어 어떻게 고쳤는지, 샘플을 얼마나 썼는지, 그리고 각 방법이
실제로 어떤 결과를 냈는지 정리. (single granularity 기준; chunk는 생략.
전체 수치는 `tables/single_summary.md`, 원본 JSON은 `results/`.)

## 공통 전처리

1. **z-score** — 각 차원을 평균 0, 표준편차 1로 표준화. 안 하면 "라디안 단위
   관절 vs 미터 단위 위치"처럼 스케일 큰 차원이 지표를 독점해서, 차원 수가
   아니라 단위 선택을 재게 된다.
2. **상수 차원 제거** — 분산 0인 차원(robocasa의 base_motion 등)은 NN 계열
   계산 전에 제외. 상수 차원은 모든 점을 완전 중복으로 만들어 거리 0을
   양산한다. PR/PCA는 고유값 0으로 자동 처리되므로 그대로 둔다.

## 1. PR (Participation Ratio)

**직관**: 데이터 구름이 "몇 개의 방향으로 실질적으로 퍼져 있는가". PCA의
방향별 분산 λ₁ ≥ λ₂ ≥ … ≥ λ_D 가 몇 개에 몰려 있는지를 하나의 연속값으로
요약.

**수학**: 공분산 고유값 λᵢ에 대해

    PR = (Σᵢ λᵢ)² / Σᵢ λᵢ²

극단으로 보면: 분산이 k개 방향에 균등(λ=c가 k개, 나머지 0)이면
PR = (kc)²/(kc²) = **정확히 k**. 한 방향에 다 몰리면 PR = 1. 즉 "실질적으로
몇 개 방향"의 연속값 버전이고, **컷오프(95% 같은) 선택이 없다**는 게 장점.

**한계**: 선형. 굽은 1차원 곡선(원)도 그것을 담는 평면이 2차원이면 PR ≈ 2.
그래서 진짜 차원의 **상한**으로 읽어야 한다.

**샘플**: 전체 타임스텝. (bridge 1.89M, gr1_unified 6.02M만 메모리 상한
1M/2M이 걸렸으나 uncapped 재계산으로 PR 차이 0.002~0.009 확인 → 사실상 전체와
동일.) 구현 이슈 없음 — m5 코드 그대로.

**결과** (all_trained):

| 데이터셋 | D | PR | PR/D |
|---|---|---|---|
| bridge | 7 | 6.49 | 0.93 |
| robocasa_mg | 12 (live 7) | 6.56 | 0.94 (live 기준) |
| gr1_tabletop 100demo | 29 | 8.28 | 0.29 |
| gr1_unified 1000demo | 29 | 8.29 | 0.29 |
| dexjoco_single | 22 | 5.58 | 0.25 |
| dexjoco_dual | 44 | 9.13 | 0.21 |

- **D가 7→44로 커지는 동안 PR은 5.6~9.1에 갇혀 있다** → PR/D 0.93 → 0.21로
  단조 감소. 유효 방향 수는 임바디먼트가 복잡해져도 거의 늘지 않는다.
- 그룹별로는 dexjoco의 연속 hand가 붕괴 지점: hand(16) 3.44, dual hand(32)
  6.54 (PR/D 0.20~0.22) vs arm 4.66~7.62 (0.64~0.78), 단순 EEF 5.5~5.6 (0.92+).
- gr1 100demo vs 1000demo(24태스크, 6.0M ts)가 전 그룹에서 사실상 동일
  (arm 7.99/7.97, all 8.28/8.29) — 데이터 24배·태스크 다양성 추가에도 불변.
  이 값은 데이터셋 크기가 아니라 임바디먼트의 성질.
- 기존 m5(400 에피소드) 값을 소수 둘째 자리까지 재현 — 서브샘플이 이미
  수렴해 있었음을 확인.

## 2. TwoNN (Facco et al. 2017)

**직관**: 각 점에서 최근접 이웃 거리 r₁, 두 번째 이웃 거리 r₂를 잰다.
**차원이 높을수록 r₂/r₁ → 1** (고차원에서는 반경을 조금만 키워도 부피가
폭발해 두 번째 이웃이 첫 번째 바로 뒤에 있음). 1차원 선 위에서는 r₂가 r₁의
2배도 가능. 이 비율 분포만으로 차원을 역산.

**수학**: 국소 균일 밀도 가정하에 μ = r₂/r₁ 은 Pareto 분포:
P(μ > x) = x^(−d). 따라서

    −log(1 − F(μ)) = d · log μ

각 점의 μ를 모아 경험적 CDF F를 만들고, log μ vs −log(1−F)를 그리면 원점을
지나는 직선이 되며 **기울기가 d**. 관례대로 μ 상위 10%는 버림(국소 균일성이
깨지는 꼬리).

**의미**: 선형 가정 없음 → 굽은 매니폴드의 진짜 차원. 대신 노이즈 방향도
차원으로 세서 과대추정("shadow dimension")하고, d > log(n)이면 과소추정.

**고친 것 (중요)**: 첫 실행에서 dexjoco TwoNN이 **1.4~1.6**으로 나왔다.
44-DoF가 1.5차원일 리 없고, 원인은 30Hz 궤적 데이터에서 **한 점의 최근접
이웃이 거의 항상 자기 자신의 다음 타임스텝**이라는 것. 그러면 액션 매니폴드가
아니라 **궤적이라는 1차원 곡선**의 차원을 재게 된다. 해결: NN 계열 계산 전에
**25 스텝마다 1개만 남기는 시간 솎아내기(stride 25)** 적용 → 3.2~5.7로 정상화.
완전 중복점(r₁=0)은 μ 발산을 막기 위해 제거하고 개수를 기록.

**샘플**: stride-25 후 풀에서 **10,000점 × 5회 독립 부트스트랩**, 평균±표준편차
보고. 전체를 안 쓴 이유: (a) NN 그래프가 ~O(n²), (b) 궤적 문제로 어차피
솎아야 함. 부트스트랩 표준편차 ±0.1 이하 = 10k 충분의 증거.

**결과** (all_trained, 평균±부트스트랩 std):

| 데이터셋 | D | TwoNN | TwoNN/D |
|---|---|---|---|
| bridge | 7 | 5.71±0.09 | 0.82 |
| robocasa_mg | 7 (live) | 5.50±0.06 | 0.79 |
| gr1_unified 1000demo | 29 | 5.14±0.04 | 0.18 |
| dexjoco_single | 22 | 5.09±0.00 | 0.23 |
| dexjoco_dual | 44 | 3.19±0.02 | 0.073 |

- 비선형으로 봐도 결론 동일: D가 6배 커지는 동안 TwoNN은 오히려 5.7 → 3.2로
  **내려간다**. 비율로는 0.82 → 0.073 — PR보다 더 극단적인 붕괴.
- 저DoF EEF에서는 PR과 거의 일치 (bridge 6.49 vs 5.71) = 그쪽은 거의 평평한
  full-rank 구름. 고DoF에서는 PR 밑으로 내려감 (dual 9.13 vs 3.19) = 매니폴드가
  굽어 있어서 선형 상한(PR)이 과대평가한다는 뜻.
- dexjoco_dual의 3.19라는 절대값은 과소추정 편향(d > log n)이 섞여 있을 수
  있어, "PR 상한 9.1과 비선형 하한 3.2 사이"로 인용하는 것이 안전.
- **gr1 hand는 NaN** — 이진 명령이라 최근접 거리가 전부 0. 버그가 아니라
  "연속 매니폴드가 없다"는 올바른 판정.

## 3. MLE (Levina–Bickel 2004)

**직관**: TwoNN과 같은 아이디어(이웃 거리 성장 속도 → 차원)를 이웃 2개가
아니라 **k개(10~20)로 확장**해 분산을 줄인 버전. TwoNN의 교차 검증용.

**수학**: 점 x의 j번째 이웃 거리 T_j. d차원에서 반경 r 안 이웃 수 ∝ r^d
(Poisson 근사)의 우도를 최대화하면 점별 닫힌 형태:

    d̂_k(x) = [ (1/(k−1)) Σ_{j=1}^{k−1} log( T_k(x) / T_j(x) ) ]^(−1)

읽는 법: k번째 이웃까지 가는 동안 거리들이 **천천히 벌어지면**(T_j들이 T_k에
다닥다닥 = log 비율 작음 = 역수 큼) 고차원, **빨리 벌어지면** 저차원. 점별
추정의 집계는 산술평균이 아니라 **역수 평균의 역수**(MacKay–Ghahramani 보정;
원 논문의 산술평균은 위로 편향). k = 10~20을 훑어 평균(k 하나에 과적합 방지).

**샘플/구현**: TwoNN과 동일한 stride-25 + 10k×5 부트스트랩. 거리 0(중복)은
NaN 처리해 log 발산 방지.

**결과** (all_trained):

| 데이터셋 | D | MLE | (TwoNN) |
|---|---|---|---|
| bridge | 7 | 5.32 | 5.71 |
| robocasa_mg | 7 (live) | 5.36 | 5.50 |
| gr1_unified 1000demo | 29 | 4.38 | 5.14 |
| dexjoco_single | 22 | 5.23 | 5.09 |
| dexjoco_dual | 44 | 3.72 | 3.19 |

- 교차 검증 역할을 그대로 수행: 모든 데이터셋에서 TwoNN과 ±0.8 이내로 일치,
  순서(어느 데이터셋이 더 저차원인가)도 동일. 두 독립 NN 추정기가 같은 답 →
  TwoNN 결과가 그 방법 특유의 artifact가 아님.
- 역시 D=44에서도 3.7 — 비선형 유효 차원은 DoF를 따라가지 않는다.
- gr1 hand는 TwoNN과 같은 이유로 NaN.

## 4. Cdim (상관차원, Grassberger–Procaccia)

**직관**: 이웃 몇 개가 아니라 **모든 점 쌍의 거리** 사용. "반경 r 안에 드는 점
쌍 비율 C(r)이 r을 키울 때 얼마나 빨리 자라는가". d차원 매니폴드 위라면 반경
r짜리 공 안의 점 수 ∝ r^d 이므로:

    C(r) ∝ r^d   ⇒   d = d log C(r) / d log r

log–log에서 쌍거리 CDF의 기울기 = 차원.

**의미**: 비선형이며, 국소(이웃 1~2개)가 아니라 **선택한 반경 스케일**의
차원을 잰다. 세 비선형 추정기 중 가장 거시적이고 대체로 가장 작은 값.

**고친 것 (가장 손이 많이 감)**: 로봇 액션은 **scale-free가 아니다** — 작은
반경에서는 점 구름이 궤적 곡선(기울기 ~1)으로 보이고, 반경을 키워야
에피소드를 가로지르는 매니폴드가 보인다. "하나의 기울기"가 존재하지 않으므로
표준 레시피(C ∈ [0.1%, 10%] 적합)를 그대로 쓰면 궤적 스케일에 걸린다(실제로
gr1 hand에서 0.13 같은 무의미한 값). 수정:

- (a) 적합 창 이원화 — **short**(C 0.1~10%, 궤적 스케일 진단용)와 **mid**(C
  5~50%, 에피소드 간 매니폴드 스케일)를 따로 보고, mid를 주 지표로 채택
  (mid 쪽 R² 0.97~1.00으로 안정적).
- (b) 반경별 국소 기울기 곡선 전체를 저장 (`figs/*_corrdim_scale.png`) —
  하나의 숫자 뒤에 숨지 않게.
- (c) 중복 쌍(거리 0)은 로그 불가로 제거, 비율 > 5%면 "이산 데이터, 신뢰
  불가" 경고를 결과에 명시 — gr1 hand가 정확히 이 경우.

**샘플**: 쌍거리라 O(n²) 메모리 → **5,000점 서브샘플**(쌍 ~1,250만 개),
stride-25 적용 후 추출.

**결과** (all_trained, mid 창 = 주 지표, R² 0.97~1.00):

| 데이터셋 | D | Cdim (mid) |
|---|---|---|
| bridge | 7 | 2.61 |
| robocasa_mg | 7 (live) | 2.69 |
| gr1_unified 1000demo | 29 | 2.80 |
| dexjoco_single | 22 | 3.99 |
| dexjoco_dual | 44 | 4.26 |

- 세 비선형 추정기 중 가장 작은 값(예상대로 — 가장 거시적 해상도).
  **D가 7→44인데 Cdim은 2.6→4.3**: 거시 스케일에서 보면 어느 임바디먼트든
  액션은 3~4차원짜리 구조 위에 있다. 비율로는 0.37 → 0.10.
- 국소 기울기 곡선(`figs/single_corrdim_scale.png`)이 스케일 의존성을 그대로
  보여줌: 작은 반경에서 ~1(궤적), 중간 반경에서 위 값으로 상승. "로봇 액션의
  차원"은 단일 숫자가 아니라 스케일의 함수라는 것 자체가 하나의 결과.
- gr1 hand는 short 창에서 0.13 같은 무의미한 값 + 중복 쌍 경고 → 이산 판정과
  일관.

## 5. pc95 (PCA 95% 분산 PC 개수)

**직관**: PR과 같은 고유값 스펙트럼에서 "분산의 95%를 설명하는 데 주성분 몇
개가 필요한가". 가장 익숙하고 리뷰어가 바로 이해하는 지표.

**수학**: 누적 설명분산이 95%를 넘는 최소 k:

    pc95 = min{ k : (Σ_{i≤k} λᵢ) / (Σᵢ λᵢ) ≥ 0.95 }

**PR과의 관계**: 같은 스펙트럼의 다른 요약. PR은 컷오프가 없는 대신 큰
고유값에 민감, pc95는 꼬리 분산까지 세므로 항상 PR보다 큼 (gr1: PR 8.3 vs
pc95 15). "95%가 자의적"이라는 비판에 대비해 **pc90/95/99 셋 다 계산**했고 셋
모두에서 데이터셋 간 순서 동일 확인 (민감도 분석).

**샘플**: PR과 동일 (사실상 전체).

**결과** (all_trained, pc90 / pc95 / pc99):

| 데이터셋 | D | pc90 | pc95 | pc99 | pc95/D |
|---|---|---|---|---|---|
| bridge | 7 | 6 | 7 | 7 | 1.00 |
| robocasa_mg | 12 (live 7) | 6 | 7 | 7 | 1.00 (live) |
| gr1_unified 1000demo | 29 | 12 | 15 | 18 | 0.52 |
| dexjoco_single | 22 | 11 | 14 | 18 | 0.64 |
| dexjoco_dual | 44 | 15 | 22 | 33 | 0.50 |

- 꼬리 분산까지 세는 가장 보수적인 지표라 비율 붕괴가 제일 완만하다
  (1.00 → 0.50). 그래도 방향은 동일: 고DoF일수록 절반 이하의 PC로 95%가 찬다.
- **민감도 분석**: pc90/95/99 세 컷오프 모두에서 데이터셋 간 순서가 동일 —
  "95%는 자의적"이라는 비판에 대한 방어가 실측으로 확보됨.
- 그룹별로는 역시 연속 hand가 극단: dexjoco_single hand 16 → pc95 9,
  dual hand 32 → pc95 14 (절반 이하) vs EEF 그룹들은 pc95 = D (full-rank).
- 다섯 지표의 순서 관계 Cdim ≤ TwoNN/MLE ≤ PR ≤ pc95 ≤ D가 모든 데이터셋에서
  유지 — 하한(비선형)과 상한(선형)이 D보다 한참 아래에서 서로를 감싸는 구조.

## 한눈에 비교

| 지표 | 무엇을 재나 | 가정 | 편향 방향 | 샘플 |
|---|---|---|---|---|
| PR | 분산이 퍼진 방향 수 (연속값) | 선형 | 상한 (굽으면 과대) | 전체* |
| pc95 | 95% 분산에 필요한 PC 수 | 선형 + 컷오프 | 상한, PR보다 큼 | 전체* |
| TwoNN | 1·2번째 이웃 거리비 분포 | 국소 균일 밀도 | 노이즈에 과대, d>log n에 과소 | stride25 + 10k×5 |
| MLE | k-이웃 거리 성장의 우도 | 국소 Poisson | TwoNN 유사, 분산 작음 | stride25 + 10k×5 |
| Cdim | 쌍거리 CDF의 log–log 기울기 | 스케일링 구간 존재 | 대체로 가장 작음 | stride25 + 5k |

\* bridge/gr1_unified만 메모리 상한(1M/2M 행)이 걸렸고, uncapped 재계산으로
동일함(ΔPR ≤ 0.009)을 확인.

**논증 구조**: 선형(PR/pc95)이 위에서 누르고 비선형(TwoNN/MLE/Cdim)이
아래에서 받치는데, D가 7→44로 커지는 동안 다섯 개 전부 한 자릿수에 머문다 →
d/D 감소는 특정 추정기의 artifact가 아니다.
